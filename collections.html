Collections

This list below contains pointers to official and community-contributed dev container assets, including Features and Templates. Collections on this list are continuously crawled for liveness, and can be presented in UX of spec supporting tools (i.e. it will be presented in the GitHub Codespaces and VS Code Dev Containers UX).

Third-Party Content

Community-contributed Features and Templates are maintained by their respective publishers. Inclusion in this index does not mean their code or subsequent updates have been security-reviewed or endorsed by the Dev Container maintainers. Features execute installation code, and Templates can configure commands that run when a container is built or started. Only use content from publishers you trust, and review the source and configuration before use. You are responsible for assessing its suitability and security risks for your environment.

To add your own collection to this list, please create a PR editing this yaml file.
